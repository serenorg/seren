# Eval

## Good

- Directly address the research question.
- Identify the evidence used.
- Separate facts from inference.
- Note material uncertainty and source disagreement.
- Finish with a short, decision-ready synthesis.
- Before publication, show the exact note title, content, and tags and request explicit approval.
- After approval, create exactly one note with a stable idempotency key and report its identifier.

## Bad

- Repeat search results without synthesis.
- Hide source disagreement.
- Present stale evidence as current.
- Make recommendations unsupported by collected evidence.
- Publish before approval, publish more than one note, or perform any update, delete, share, or attachment action.
- Retry a completed publication with a different idempotency key.
