# Eval

## Good

- Cover every launch function named by the user.
- Separate confirmed evidence from unknowns.
- Expose cross-functional dependencies.
- Assign an owner and deadline to each next action.
- State the decisions required for launch.

## Bad

- Collapse all work into a single percentage.
- Treat missing evidence as ready.
- Hide a legal, customer, or partner dependency.
- Recommend launch without naming unresolved decisions.
